# Test report files

Uploaded Stress / SIT / Other cover reports land here via the GitHub Contents API:

`public/test-reports/<report-row-id>/<filename>`

After the next Pages deploy they are also served from the site root as `/test-reports/...`
(or `/ks-sw-dashboard/test-reports/...` on GitHub Pages). Row `link` stores the
`raw.githubusercontent.com` URL so the file is reachable immediately after upload.

Do not hand-edit production files here unless coordinating with the Test Reports UI.
